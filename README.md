# متجر المنار

## ربط Supabase

1. افتح مشروع Supabase ثم **SQL Editor**.
2. الصق محتوى `supabase-setup.sql` وشغّله مرة واحدة. الملف متوافق مع جداولك الحالية (`products.name` و`profiles.display_name`)؛ يضيف جداول السلة والمفضلة والعناوين، ويزرع منتجات أولية إذا كان جدول المنتجات فارغًا.
3. من **Authentication → URL Configuration** أضف عنوان الموقع المحلي إلى قائمة Redirect URLs، مثل `http://localhost:5173/**`، وعنوان الموقع المنشور عند إطلاقه.
4. بعد تفعيل مزوّد Google أو Facebook (الخطوات أدناه)، أنشئ حسابك من المتجر، ثم شغّل استعلام منح المالك الموجود في آخر ملف SQL بعد استبدال البريد ببريد حسابك.

المتجر يستخدم عنوان المشروع ومفتاح النشر العام `sb_publishable` في `app.js`. هذا المفتاح مخصص للواجهة. لا تضع مفتاح `sb_secret` أو أي مفتاح خدمة في ملفات المتصفح.

## التشغيل المحلي

ثبّت Node.js 20.19 أو أحدث، ثم من هذا المجلد شغّل `npm install` وبعده `npm run dev`. افتح العنوان المحلي الذي يعرضه Vite؛ يجب تشغيله عبر خادم محلي حتى تعمل جلسات Supabase والوحدات البرمجية.

## تسجيل الدخول بـ Google وFacebook

نافذة الحساب تستخدم تسجيل الدخول الاجتماعي عبر Supabase فقط. لتفعيل الزرين في بيئتك:

1. من **Supabase → Authentication → Providers** فعّل Google وFacebook، وأدخل Client ID وClient Secret الصادرين من إعدادات كل مزوّد.
2. انسخ **Callback URL** الظاهر في إعدادات كل مزوّد داخل Supabase إلى قائمة Redirect/Callback URLs في Google Cloud وMeta for Developers. يكون عادةً `https://<project-ref>.supabase.co/auth/v1/callback`.
3. من **Supabase → Authentication → URL Configuration** اجعل عنوان المتجر عنوان الموقع الأساسي، وأضف عناوين التطوير والنشر إلى Redirect URLs (مثل `http://localhost:5173/**`).
4. جرّب الزرين على الموقع المنشور وlocalhost بعد حفظ إعدادات كل مزوّد.

## حسابات المستخدمين

RLS يعزل الملف الشخصي والسلة والمفضلة والعناوين والطلبات لكل مستخدم. ملف الإعداد يستبدل سياسات RLS الحالية على `profiles` و`products` و`orders` بسياسات الحساب والمالك الخاصة بهذا المتجر. دور المالك يُقرأ من `profiles.role`؛ لا تمنحه من تسجيل المتجر.

## ملاحظات الطلبات

يحفظ المتجر الطلب في Supabase ثم يفتح واتساب برسالة جاهزة للمراجعة والإرسال. أدخل رقم المتجر في `STORE_WHATSAPP` أعلى `app.js` بصيغة دولية من دون `+` أو مسافات.
